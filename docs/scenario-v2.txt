# 미개장 수족관
### 인터랙티브 소설 설계 문서 v3.3

원작: 「괴담에 떨어져도 출근을 해야 하는구나」 (카카오페이지 연재)
성격: 2차 창작 / 비영리 / 무료 배포
플레이어: 김솔음 시점
세이브·로드: 없음 (예외 1건, 11번 엔딩 항목 참조)

**v3.3 변경사항**
- 8장 선택지 D(백사헌한테 맡긴다) 복원 — 엔딩 3 진입로 재확보
- 8장 C(협상한다)의 반응 대사 신설 (v3.0 이후 누락되어 있던 부분)
- 9장 도입부를 `9장-재심사-D`(D 전용)와 `9장-재심사`(default)로 분리
- 공통 합류 지점 `9장-키스` 신설 — D의 주도적 전개와 default의 "이리 와/키스해줘" 요청이 서로 모순되지 않도록 씬 경계 조정
- 전체 구조도·판정 로직·엔딩 3 조건줄에서 도달 불가 표시 제거

**v3.2 변경사항 (참고용 — 이후 복원됨)**
- 8장 선택지 D 전면 삭제, 엔딩 3 도달 불가 상태로 전환됐던 이력

**v3.1 변경사항**
- 엔딩 4 오염도 하한 36 → **30** (도달 불가 문제 해결)
- 30~35 겹침 구간에서 `FLAG_기억` 우선 처리 규칙 신설

**v3.0 변경사항**
- 페이지 마커 전면 삽입 (개발 구현용)

- 9-A 컷신에 오염 상한(36~65) + `FLAG_손재주` 조건 추가 → 엔딩 6 잠금 해제

- 8장 A/C의 9장 스킵 경로 명시
- 8장 B 라벨 변경, 7장 C 병행 처리, 3장 종이 복원, 엔딩 2·5 차별화
- 14-5 문구를 실제 본문에 맞게 수정

## 1. 로그라인 및 컨셉

> **살아서 나가려면 서로를 사랑하면 안 되고,**
> **함께 있으려면 영원히 갇혀야 한다.**

남해지사 환풍구를 빠져나온 김솔음과 백사헌이, 작업자 구역의 '관계자 외 출입금지' 문을 열고 들어가면서 시작된다. 문은 닫히는 순간 사라지고, 그곳은 개장한 적 없는 수족관이다.

이 수족관은 손님을 기다리지 않는다. **개체를 기다린다. 그것도 페어로.**

## 2. 세계관 — 미개장 수족관

### 2-1. 정체

개장 준비 중에 멈춘 수족관. 수조는 다 지어졌는데 채울 개체가 없다. 그래서 이 공간은 스스로 생물을 수집하기 시작했고, 조건이 하나 붙는다 — 반드시 **페어**로.
한 쌍이어야 번식하고, 번식해야 전시가 유지되고, 전시가 유지되어야 이 수족관은 비로소 '개장할 수 있는 상태'가 되는 것이다.

정면 안내판에는 이렇게 적혀 있다.

```
______ 아쿠아리움 · 개장 예정
```

**이름 자리가 비어 있다.** (11번 엔딩 복선)

### 2-2. 핵심 규칙

**규칙 1. 입고는 2개체 단위다.**
혼자 들어온 것에는 짝을 붙여준다.

**규칙 2. 적합 판정을 받은 페어는 영구 사육된다.**
안전하다. 쾌적하다. 굶지 않는다. 대신 영원히 나갈 수 없고, 몸이 물 생활에 맞게 변형된다. 이 변형이 **오염**이다.

**규칙 3. 부적합 판정을 받은 개체는 방출된다.**
버려진다는 뜻이고, 그게 이곳의 **유일한 출구**다.

**규칙 4. 용이한 수족관 관리를 위해 방출은 한 번에 한 개체씩만 가능하다.**

**규칙 5. 오래 갇혀 있을수록 오염은 진행된다.**
방출되어도 **언제 나가느냐**가 전부다. 빨리 나가면 사람인 채로 나가고, 늦게 나가면 사람이 아닌 채로 나간다. 시간이 비용이 되는 구조.

**규칙 6. 페어로 확정된 개체는 분리할 수 없다.**
관리 편의상 페어는 하나의 단위로 취급된다. 한쪽만 방출하거나 한쪽만 사육할 수 없다.

**규칙 7. 오염되지 않은 개체는 전시할 수 없다.**
물에서 살지 못하는 것을 수조에 넣을 수는 없다. 전시하려면 최소한의 오염이 필요하다.

**규칙 8. 단독 전시가 가능해지면 페어는 파기된다.** *(v3 신설)*
한 개체만으로 전시 가치가 충분해지면 짝은 불필요해진다. 이때 페어는 해체되고, 남은 쪽은 부적합으로 재분류되어 방출된다. (엔딩 10·7의 근거)

> **규칙 6 + 7이 만드는 빈틈 (1번 동행 엔딩의 근거)**
>
> **서로를 인정했는데 아직 오염되지 않은 페어**는 이 수족관이 처리할 방법이 없다.
> 페어라 떼어낼 수 없고(규칙 6), 오염되지 않아 해양생물 개체가 아니니 수조에 담아둘 수 없다(규칙 7).
> 결국 통째로 뱉어낸다.
>
> 조건 두 개가 서로 반대 방향이라는 게 핵심이다.
> - 페어가 되려면 → 가까워져야 한다
> - 오염되지 않으려면 → 빨리 끝내야 한다
>
> **고백이 곧 게임 메커닉이 된다.** 고백 해야 페어가 되고, 빨리 상대에게 사랑을 느껴야 오염되지 않는다.
>
> 그리고 이것이 지금까지 한 번도 성공하지 못한 이유이기도 하다.
> 매번 한쪽이 끝까지 인정을 안 했거나(페어 미성립), 인정할 때쯤엔 이미 늦었다(전시 가능).

### 2-3. 명패 시스템

수조마다 명패꽂이가 있다. 명패가 붙는 순간 그 안의 것이 정의되고 물 속에서 숨이 쉬어진다. 사람도 예외가 아니다.

오염도가 오르면 **명패에 이름이 저절로 채워지기 시작한다.** 본인은 그걸 이상하게 여기지 않는다.

### 2-4. 안내 방송

낮과 밤이 없다. 반복되는 안내 방송이 시간을 대신한다. 방송 내용이 미묘하게 바뀌는 것이 오염도의 지표로 기능한다.

- 오염 낮음: *"개장까지 조금만 더 기다려 주십시오."*
- 오염 중간: *"개체 A, 수온이 맞지 않으십니까?"*
- 오염 높음: *"관람객 여러분, 유리에 손대지 마십시오."* (이제 두 사람이 유리 안쪽에 있다는 뜻)
- 오염 최대: 방송이 김솔음의 이름을 부르기 시작한다.

### 2-5. 판정은 공정하지 않다

**김솔음은 인간 판정이다.**

**수족관이 김솔음을 마음에 들어 한다.**

괴담들은 원래 김솔음을 좋아하는 편이다. 이 수족관도 예외가 아니다. 김솔음은 건강하고, 유능하고, 매력적이고, 무엇보다 이 공간의 규칙을 빨리 이해한다. 사육하기 좋은 개체다. 말귀를 알아듣는 개체.

그래서 판정은 처음부터 기울어져 있다.

```
개체 A(김솔음) ─ 적합
개체 B(백사헌) ─ 부적합
```

수족관은 김솔음을 갖고 싶다. 그러려면 옆에 붙어 있는 남자를 치우고 더 보기 좋은 짝으로 갈아 끼워야 한다. **백사헌의 부적합은 심사 결과가 아니라 정리 대상 통보에 가깝다.**

> **설계 의도**: 판정이 편향돼 있다는 건 뒤집을 수 있다는 뜻이다. 객관적 등급이면 백사헌은 절대 못 이긴다. 하지만 이건 수족관의 취향 문제라서 설득할 여지가 생긴다. 2막 전체가 "조작된 심사에 항의하는 과정"이 된다.

### 2-6. 백사헌의 진짜 적은 건물이다

백사헌은 지금 수족관과 경쟁하고 있다. 그리고 그걸 인정할 수가 없다. 인정하려면 자기가 김솔음을 뭘로 생각하는지부터 정리해야 하니까.

그가 마주하는 것들:
- 김솔음 옆에 세워지는 아름다운 대체 개체들
- 김솔음에게만 유독 맞는 수온, 조명, 자리
- 자기한테는 안 열리는 문이 김솔음 앞에서는 열리는 것

### 2-7. 백사헌의 갈림길 (게임 전체의 주제)

- **나간다** = 무시하고 혼자 탈출한다. 인간인 채로. → 순수 생존 논리. **퇴행**
- **남는다** = 적합 판정을 받아내야 한다 = 개체가 되어야 한다 = 변형된다. → **성장**

평생 살아남는 것만 계산해온 남자가, "쓸모없다"는 판정 덕분에 홀로 살아 나간다. 원하던 결과를 최악의 방식으로 받는다.

> **3막 디폴트**: 아무것도 하지 않으면 **백사헌은 나가고 김솔음은 갇힌다.**
> 그는 이미 방출 대기열에 올라 있다(3장). 즉 **가만히 있으면 산다.**
> 그가 움직이려면 자기 목숨을 걸어야 하고, 안 움직이면 그냥 평소의 자신이 된다.

## 3. 수치 시스템

화면 중앙 상단에 3개 게이지 상시 표시.

### 관계도 (0~100)

| 구간 | 상태 |
|---|---|
| 0~30 | 서로 이용하거나 버릴 수 있음 |
| 31~70 | 협력하지만 감정은 인정하지 않음 |
| 71~100 | 서로를 구하기 위해 위험을 감수함 |

**함정**: 이 세계관에서 관계도는 수족관이 읽는 "페어의 적합도"이기도 하다. 높을수록 **사육 확정**에 가까워진다. 무작정 높이면 6번 엔딩으로 간다.

### 주도권 (-100 ~ +100)

```
김솔음 우위 ← -100 ··· 0 ··· +100 → 백사헌 우위
```

| 구간 | 상태 |
|---|---|
| -100 ~ -34 | 김솔음이 판단하고 백사헌을 끌고 감 |
| -33 ~ +33 | 대등 |
| +34 ~ +100 | 백사헌이 김솔음을 보호·통제함 |

> **주의**: 주도권이 +34 이상이고 오염도가 36~65 구간이면 9장에서 **플레이어의 선택권이 박탈된다.**
> 백사헌이 먼저 움직인다. 이것이 그의 "보호"가 어떤 형태인지를 보여주는 메커닉이다.

### 오염도 (0~100)

| 구간 | 상태 | 증상 |
|---|---|---|
| 0~25 | 현실 판단 가능 | 없음 |
| 26~50 | 환청, 기억 왜곡, 반복 행동 | 물 밖이 답답해짐. 피부가 건조한 걸 못 견딤 |
| 51~75 | 괴담 규칙 내면화 | 명패에 이름이 저절로 채워짐. 이상하게 여기지 않음 |
| 76~100 | 정체성 붕괴 | 유리 안쪽이 편해짐. 인간의 말을 잃어감 |

**오염도는 시간이다.** 챕터 진입마다 **+2** 자동 상승.

**9장 분기 임계값**

| 오염도 | 상태 | 가능한 결말 |
|---|---|---|
| 0~29 | 전시 불가 | 1·2·3·5·12번 |
| 30~35 | 전시 불가 (겹침 구간) | 위 + **4번** (`FLAG_기억` 보유 시 우선) |
| 36~65 | 애매 | 4·8·9-A·9-B |
| 66~75 | 전시 가능 | 6번 |
| 76~ | 단독 전시 가능 (페어 파기) | 7·10·11번 |

### v3 오염도 밸런싱 검증

```
자동 상승           18  (+2 × 9챕터)
1장 C 관찰          -5  →  13
3장 B 관찰          -5  →   8
6장 C 정보공유     +10  →  18
7장 자판기         +10  →  28
8장 B              +5  →  33
─────────────────────────────
최종 33 → 1번 동행(35 이하) 달성 ✓
```

**관찰 선택지(-5) 중 하나라도 놓치면 38이 되어 봉쇄된다.** "눈여겨본 플레이어만 진엔딩에 간다"는 구조는 유지되면서, 정보공유와 자판기를 둘 다 쓴 플레이어도 통과할 수 있다.

## 4. 캐릭터 가이드

### 김솔음 (플레이어)

- 백사헌을 **"백사헌"**이라고 부른다. **반말**을 쓴다.
- 스스로 "쫄보"라 하지만 실제로는 위기에서 탁월한 판단력·행동력을 보인다.
- 이타적이고 선하지만 본인은 "합리적 선택"이라고 축소해서 설명한다.
- 상황에 맞춰 성격·컨셉을 연기하는 능력이 발군이다.
- 관계의 온도를 잘 드러내지 않아서, 백사헌이 보내는 신호를 자주 놓친다.

### 백사헌

- 김솔음을 **"저기요", "그쪽"**이라고 부른다. **급해지면 "김솔음"**이라고 부른다.
- **반존대**. 껄렁하고 거슬리는 말투.
- 실익 최우선. 타인을 이용하는 데 거리낌 없지만 가학적 쾌감은 없다.
- 동정심, 양보 등의 감정을 느끼면 죽는다는 걸 반복 학습해서, 생존에 방해되는 감정을 즉시 차단한다.
- 실제 감정과 반대로 말한다. 인정받고 싶을 때 우회적·시비조로 찔러본다.
- 보호하고 싶을 때도 "거래·이득 제공"을 가장해서 접근한다. 애정 표현의 다른 언어를 모른다.
- 관찰력과 손재주가 뛰어나다. 그림도 잘 그릴 정도. (루프 트위스트의 핵심 단서 / 4장 발급기 / 9장 컷신)

### 대사 작성 시 주의

**백사헌**
- 말이 많다. 감정이 고조될수록 존대보다 반말을 한다.
- 감정을 설명하는 문장을 대사 안에 붙이지 않는다.
- 정말 감정이 튀는 지점에만 욕설. (`씹..` / `xx` / `젠장` 일부 가림 표기)

**김솔음**
- "응.", "뭐.", "왜." 같은 한두 글자 대답을 적극적으로 쓴다.
- 이름을 부르는 것 자체가 무기다. `"백사헌."` 한 줄로 상황을 끊는다.

## 5. 문체 원칙

### 5-1. 관찰 다음엔 반드시 반응이 온다 (최우선 규칙)

**김솔음은 카메라가 아니다.**

"보았다 / 들렸다 / 지나갔다"로 문단을 끝내지 않는다. 관찰·사건 문장 뒤에는 **몸 반응, 감각, 해석, 의문 중 하나**가 반드시 붙는다.

```
X   유리 안쪽에서 뭔가 움직였다.

O   유리 안쪽에서 뭔가 움직였다. 손이 저절로 멈췄다.
    저기 아무것도 없었는데.
```

### 5-2. 짧은 한 줄 문단으로 박자를 끊는다

`"정적이 흘렀다."` `"뒤를 돌아봤다."` 처럼 한 문장이 온전히 하나의 문단을 이루는 구간을 자주 넣는다. **페이지 마지막 줄에 이런 문장을 배치하면 다음 버튼을 누르게 만드는 효과가 크다.**

### 5-3. 따옴표 없는 내적 목소리

캐릭터의 속말이 따옴표 없이 서술 사이에 그냥 끼어든다. `~라고 생각했다` 꼬리를 자른다.

### 5-4. 대화는 짧고 무뚝뚝하게

설명이 붙으면 사고다. 다정한 대사도 부연하지 않는다.

### 5-5. 장면 전환과 콜백

- 시간/장소가 바뀌면 `* * *` 로 명확히 끊는다.
- 주요 콜백 대상:
  - **"협조해라"** (5장 → 6장)
  - **측정실** (5장 → 9장, 같은 방 같은 자세)
  - **발급기에서 떼어낸 판** (4장 → 9장 컷신)
  - **라벨 없는 캔** (7장 → 9-A/9-B 엔딩)
  - **꼼꼼하게 접힌 종이** (3장 → 트위스트)
  - **빈 이름 자리** (1장 → 11번 엔딩)
  - **닳은 키보드** (4장 → 트위스트)
  - **"문 아니니까"** (2장 → 8번 엔딩)

### 5-6. 페이지 분할 원칙

- 한 페이지 200~250자
- **대사 주고받음은 자르지 않는다.** 한 페이지 안에서 마무리
- **반전이나 정보 공개 직전에서 끊는다.** 다음 페이지 첫 줄이 공개가 되도록
- 짧은 한 줄 문단은 페이지 끝에 배치

## 6. 루프 트위스트 정본

### 6-1. 이번이 처음이 아니다

이 수족관은 백사헌과 김솔음을 여러 번 마주했다. **어떤 회차엔 백사헌이 남았고, 어떤 회차엔 김솔음이 남았다.**

그래서 안에는 두 사람 모두의 흔적이 있다. **백사헌이 접은 종이와 그의 필체로 쓴 메모, 그리고 김솔음의 손자국.**

### 6-2. 이 공간은 이름은 지우고 흔적은 남긴다

이름과 나간 사람의 기억은 지우지만 물건은 못 지운다. 이름을 기록해주지 않았던 것들이 모여 만든 공간이라서, 작동 방식 자체가 그렇다.

### 6-3. 자판기가 루프를 만든다

밖으로 나간 쪽은 동전을 넣고 특정 음료를 뽑으며, 자판기로 안쪽과 통신할 수 있다.
음료 캔 바닥에 짧은 문장을 써서 도로 자판기에 넣으면, 목표한 상대방이 자판기를 사용할 때 그 음료를 뽑는 식.
대가는 **내가 가지고 있는, 메시지를 보내고 싶은 쪽에 대한 기억**이다.

> **한 번 메시지를 주고받을 때마다, 그 사람을 조금씩 잊는다.**

기억이 다 없어지고 나면, 이유도 모른 채 본능적으로 끌려 그 공사 구간으로 다시 걸어 들어간다. 기억은 바닥났어도 **몸이 기억하니까.**

### 6-4. 지금까지 단 한 번도 동시에 나간 적이 없다

매번 한 명이 남았고, 그래서 매번 루프가 다시 돌았다. **1번 동행이 진엔딩인 이유가 여기 있다.** 그게 유일하게 시도된 적 없는 방법이다.

3장 명패실의 메모가 그래서 무섭다.

> *이 방법 안 먹힘.*

어떤 방법인지는 안 적혀 있다. 몇 번을 실패했는지도.

### 6-5. 닳은 키보드 (확정 복선)

4장 등록소 키보드에 유독 닳은 키는 여섯 개다.

```
r t d q t g
```

수많은 사람이 이름을 넣었다면 키가 골고루 닳아야 한다. 여섯 개만 특히 닳았다는 건, **아주 적은 수의 이름을 아주 여러 번 넣었다**는 뜻이다.

두 사람 이름의 초성이다.

> 백사헌은 김솔음의 아이템을 회수하고 방출구로 걸어간다.
> "…어차피 이제 못 알아보잖아요."
> 그 말이 변명인지 확인인지는 드러나지 않는다. 백사헌은 예전의 삶으로 돌아간다.

**관계도 높음 (71 이상)**
> 백사헌이 오랫동안 곁을 맴돌며 상태를 돌본다. 김솔음이 완전히 개체가 되어 수족관에 들어간다. 멋진 생물이 생긴 수족관은 개장하고, 괴담 주민들은 예쁜 인어를 구경하며 감탄한다. 둘 다 탈출하지 못한다.
> 김솔음은 그를 알아보지 못하지만, 백사헌이 수조에 그를 보러 올 때면 때때로 공기 방울로 하트 모양을 만드는 묘기를 보여 주기도 한다.

---

### 엔딩 11. 이름님 — 메타 시크릿
**조건**: 이름 플래그 3종 이상 + 오염도 76 이상

- `FLAG_이름1` — 4장 등록소 실명 입력
- `FLAG_이름2` — 7장 자판기 이름 지불
- `FLAG_안내판기입` — 1장 안내판 재조사 후 이름 적기
- `FLAG_이름부정` — 8장 B에서 백사헌이 "김솔음"이라 부를 때 부정

이 수족관에는 이름이 없다. 안내판의 이름 자리는 처음부터 비어 있었다. **이 공간은 이름을 갖고 싶어 한다.**

```
당신은 김솔음입니다.
당신은…… 김솔음입니다.
당신은 ■■■■입니다.
당신은 [이름님]입니다.
```

UI가 전부 깨진다.

| 기존 | 변경 |
|---|---|
| 관계도 | **숭배** |
| 주도권 | **복종** |
| 오염도 | **은총** |

안내판의 빈칸이 채워진다.

```
이름님 아쿠아리움 · 개장
```

```
이름님을 아세요?
이름님은 당신을 알고 있어요.
우리도 이제 당신을 알아요.
오세요! 와서, 전시된 이름님을 보자!
같이 이름님을 숭배하자ㅏㅏㅏㅏㅏㅏㅏㅏㅏㅏㅏㅏㅏㅏㅏㅏㅏㅏ
```

선택지는 하나만 나온다.

```
[네]
```

누르면 처음 화면으로 돌아간다. 단, **타이틀과 시작 버튼 일부가 `[이름님]`으로 바뀌어 있다.**

> **개발 예외**: 이 엔딩만 `localStorage`에 불리언 플래그 1개를 저장한다. 세이브·로드 시스템과는 무관하며, 진행 상황은 저장하지 않는다.

### 엔딩 12. 인도 — 김솔음 주도
**조건**: 관계도 71 이상 / 주도권 -50 이하 / 오염도 35 이하 / 9장 A 또는 B

김솔음이 매 순간 먼저 판단하고 지시한다. 백사헌은 처음엔 반발한다.

> "내가 왜 그쪽 말을 들어야 하는데요."

하지만 판단이 매번 그를 살리자, 점점 묻지 않고 따르기 시작한다. 반출 직전에 낮게 말한다.

> "그쪽이 내 인생에 처음이에요."
> "뭐가."
> "내가 완전히 믿고, 누구 뒤를 따라가기만 하는 거."

김솔음은 대답 대신 앞장선다. 백사헌은 처음으로, 아무 계산 없이 그 뒤를 따른다.

**3번과의 차이**: 3번이 웃으며 힘을 빼는 팬서비스라면, 12번은 백사헌이 처음으로 통제를 내려놓는 성장의 결이다.

## 13. 플래그 및 판정 로직

### 13-1. 판정 순서 (v3 개정)

```
■ 8장에서 분기
  A 또는 C 선택 → 9장 스킵 → [ENDING: 9-B]
  B 또는 D 선택 → 9장 진행

■ 9장 진입 후

1단계 — 오염도 76 이상 (페어 파기)
  이름 플래그 3종+                 → 엔딩 11
  주도권 -34 이하 + 관계도 71+      → 엔딩 7
  그 외                            → 엔딩 10 (관계도 내부 분기)

2단계 — 9-A 컷신 (선택지 박탈)
  오염 36~65 AND 주도권 +34↑
  AND 관계도 71↑ AND FLAG_손재주    → 엔딩 9-A

3단계 — 9장 선택 게이트
  A(고백) + 오염 35↓
      ├ 주도권 +50↑ + 관계도 71↑ + 8장D → 엔딩 3
      ├ 주도권 -50↓ + 관계도 71↑        → 엔딩 12
      └ 그 외                            → 엔딩 1  ★진엔딩
  B(침묵) + 오염 35↓
      ├ FLAG_기억 + 오염 30↑ + 관계도 31↑ → 엔딩 4  ※최우선
      ├ 주도권 +50↑ + 관계도 71↑ + 8장D → 엔딩 3
      ├ 주도권 -50↓ + 관계도 71↑        → 엔딩 12
      ├ 관계도 71↑                       → 엔딩 2
      └ 관계도 70↓                       → 엔딩 5
  C(밀어냄)                              → 엔딩 9-B
  D(수용) + 오염 66~75                   → 엔딩 6
  E(자판기) + FLAG_라벨없음               → 엔딩 8

4단계 — 미분류 (오염 36~65 잔여)
  FLAG_기억 + 관계도 31↑           → 엔딩 4
  그 외                            → 엔딩 5
```

> **엔딩 4 진입 경로 (v3.1 수정)**
> 하한을 36 → **30**으로 낮췄다. 최소 경로 계산상 자판기에서 기억을 지불해도 36에 못 미쳐 도달이 불가능했기 때문.
>
> ```
> 자동 18 + 7장 B(기억) 10 + 8장 B 5 = 33  → 30 이상 ✓
> ```
>
> **30~35 구간이 엔딩 1·2·5와 겹치므로, B(침묵) 분기 안에서 `FLAG_기억`이 최우선한다.**
> 즉 기억을 팔아넘긴 플레이어가 고백까지 하지 않으면, 관계도·주도권과 무관하게 4번으로 간다.
> 고백(A)은 이를 덮는다 — 말로 뱉은 것은 잊히지 않는다.

> **진엔딩 도달 조건 요약**
> 오염도 35 이하 + 9장 A(고백) + **주도권 -49~+49**
> 주도권을 한쪽으로 몰면 3번이나 12번으로 빠진다. 이는 "함께 선택하는 관계"라는 1번의 주제와 일치한다.

### 13-2. 플래그 목록

| 플래그 | 획득 위치 | 사용처 |
|---|---|---|
| `FLAG_안내판` | 1장 안내판 A | 4장 키보드 추가 연출 |
| `FLAG_안내판기입` | 1장 안내판 C (재조사) | 11번 |
| `FLAG_손자국` | 2장 갈림길 A | 트위스트 |
| `FLAG_종이` | 3장 흔적 B | 트위스트 |
| `FLAG_망설임` | 3장 시험 C | 5장 B 대사 변경 |
| `FLAG_이름1` | 4장 실명 입력 | 11번 |
| `FLAG_손재주` | 4장 B (발급기) | **9-A 컷신 필수 조건** |
| `FLAG_이름2` | 7장 이름 지불 | 11번 |
| `FLAG_기억` | 7장 기억 지불 | 4번 |
| `FLAG_라벨없음` | 7장 C (조사) | 8번 |
| `FLAG_정보공유` | 6장 C | 8장 C 개방 |
| `FLAG_이름부정` | 8장 B (이름 부를 때) | 11번 |

### 13-3. 오염도 자동 상승

**챕터 진입 시마다 +2.** 총 9챕터이므로 기본 18.

8장 카운트다운 구간은 별도. 선택을 미룰수록 실시간 상승.

## 14. 개발 참고사항

### 14-1. UI

- 화면 중앙 상단에 3개 게이지 상시 표시
- 관계도·오염도는 0~100 바, 주도권은 중앙 기준 양방향 바
- **주도권 바에는 숫자를 표시하지 않고 양끝에 이름만 표기** (`김솔음 ◄──●──► 백사헌`)
- 8장부터 오염도 게이지에 카운트다운 연동
- 11번 엔딩 진입 시 게이지 라벨이 숭배 / 복종 / 은총으로 교체되고 UI가 깨짐

### 14-2. 안내 방송

오염도 구간에 따라 방송 문구 자동 교체. 플레이어가 자기 상태를 수치가 아니라 **방송 내용으로** 체감하게 하는 것이 목적.

### 14-3. 세이브·로드

없음. 예외는 11번 엔딩의 `localStorage` 불리언 1개.

### 14-4. 저작권 및 배포

- 2차 창작, 비영리, 무료 배포
- 원작·플랫폼 표기 명시
- 엔딩 0에 원작 링크 배치
- 수익화 요소 일절 없음

### 14-5. 콘텐츠 고지

*(연령 등급 표기는 별도 검토 예정. 아래는 현재 본문 기준 사실 기술.)*

- 9장 키스 장면은 구체적인 신체 접촉 묘사를 포함한다.
- 9-A 컷신에 상해 묘사가 있다(얼굴 자상, 출혈).
- 8번·7번 엔딩은 실종으로 끝난다.
- 욕설은 가림 표기로 제한적으로 사용한다.
- 배포 플랫폼의 연령 정책에 맞춰 표기 및 사전 경고를 조정할 것.

# 미개장 수족관 v0.3

「괴담에 떨어져도 출근을 해야 하는구나」 비영리 2차 창작 인터랙티브 소설의 실행 가능한 프로토타입입니다.

## 실행

1. Node.js 18 이상을 설치합니다.
2. 이 폴더에서 `npm install`
3. `npm run dev`
4. 화면에 표시되는 주소를 브라우저에서 엽니다.

배포용 파일은 `npm run build`로 생성합니다.

## 대사 수정

- 장면·대사·선택지: `src/game/scenario.js`
- 엔딩 본문: `src/game/endings.js`
- 수치·판정 규칙: `src/game/rules.js`
- 화면 구성: `src/App.jsx`
- 디자인: `src/styles.css`

일반 세이브·로드는 없습니다. 엔딩 11을 본 사실만 브라우저에 저장합니다.
